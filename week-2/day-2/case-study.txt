E-Commerce Website Automation
Problem Statement
An e-commerce company wants to automate its shopping workflow to reduce manual testing effort.

The QA Automation team must automate:
Login functionality
Product validation
Add to cart action
Dynamic table handling
Success message validation

The application contains:
Dynamic IDs
Changing class names
Dynamic tables
Navigation links

The goal is to create stable Selenium locators using:
XPath
CSS Selectors
contains()
starts-with()
XPath Axes

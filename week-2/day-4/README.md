Week 2 - Day 4: Waits, Expected Conditions & Flaky Tests

This directory contains beginner-friendly examples demonstrating:
- Implicit vs Explicit waits (polling style)
- Implementing expected conditions (wait-for helpers)
- Handling dynamic UI (element appears/disappears)
- Common causes of flaky tests and mitigation tips

All examples are pure Python simulations (no Selenium required) so you can run them locally.

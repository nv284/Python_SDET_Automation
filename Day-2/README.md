Day 2 - Control Flow & Data Structures

This folder contains lessons, examples, a small project, and two assignments focused on:

- Conditional logic: `if`, `elif`, `else`
- Nested conditions
- Loops: `for`, `while`, `break`, `continue`
- Collections: Lists, Tuples, Sets, Dictionaries
- Iteration patterns: `enumerate`, `zip`
- Hands-on tasks: process bulk test data and loop-driven automation

Work through `lessons/lesson.md`, then run examples in `examples/`. A small project and two assignments are provided in `projects/` and `assignments.txt`.

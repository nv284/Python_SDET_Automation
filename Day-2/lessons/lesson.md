Control Flow & Data Structures - Lesson

Topics covered:

- Conditional logic: `if`, `elif`, `else` with real examples like access checks and thresholds
- Nested conditions: multi-stage validation flows
- Loops: `for`, `while`, `break`, `continue` and when to use each
- Collections:
  - Lists: create, read, update, delete elements
  - Tuples: immutability and use-cases
  - Sets: ensure uniqueness, membership checks
  - Dictionaries: key-value storage and lookup patterns
- Iteration patterns: `enumerate` for indexed loops, `zip` for parallel iteration

Hands-on objectives:

- Process bulk test data (CSV-like lists) using loops and dictionaries
- Build simple loop-driven automation (retries, batching, reports)

Constraints: In examples and assignments do not use `def`/functions; write linear scripts using control flow and data structures.

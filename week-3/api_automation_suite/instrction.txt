framework flow 
-------------------
pytest execution
      ↓
Pytest discovers test files
      ↓
Imports framework utilities
      ↓
Loads config values
      ↓
Creates API client object
      ↓
Builds request
      ↓
Sends HTTP request
      ↓
API server processes request
      ↓
Response returned
      ↓
JSON parsing happens
      ↓
Assertions/validations execute
      ↓
Pytest marks PASS/FAIL
      ↓
HTML report/log generated


install 
-------------
1) pip install pytest requests pytest-html

execution 
-------------
pytest -v

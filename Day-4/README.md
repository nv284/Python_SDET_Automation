Day 4 - OOP for Automation Frameworks

This folder contains lessons, examples, a small project, and two assignments focused on object-oriented programming concepts applied to automation framework design.

Session coverage:
- Classes and objects
- Constructors and instance variables
- Inheritance and reuse
- Polymorphism (method overriding)
- Encapsulation and abstraction
- Mapping OOP to automation framework design (Page Object concept intro)

Work through `lessons/lesson.md`, run examples in `examples/`, then explore the `projects/` Page-Object-style demo and `assignments.txt`.

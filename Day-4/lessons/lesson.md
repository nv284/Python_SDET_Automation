OOP for Automation Frameworks

Topics covered:

- Classes & Objects: modeling entities used in automation
- Constructors (`__init__`) and instance variables for state
- Inheritance: sharing behavior across page objects or components
- Polymorphism: overriding methods for specialized behavior
- Encapsulation & Abstraction: hiding internals and exposing clear APIs
- Mapping to frameworks: Page Object (PO) pattern, base page classes, and reusable components

Hands-on objectives:

- Implement classes with constructors and instance state
- Create base classes and derived classes to reuse behavior
- Demonstrate method overriding for polymorphism
- Use encapsulation (private-ish attributes) and public methods
- Build a tiny Page-Object-style project simulating interactions (no external libraries required)

Note: examples and project are simple, runnable scripts that illustrate how to structure automation code.

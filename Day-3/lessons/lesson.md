Functions, *args/**kwargs, Lambdas & Modularization

Topics covered:

- Functions: define with parameters, return values, positional and keyword args
- Variable arguments: `*args` for tuples of positional args, `**kwargs` for dict of named args
- Lambda expressions: concise anonymous functions for short transformations
- Functional basics: `map`, `filter`, `reduce` (from `functools`), and when to use them
- Higher-order functions: passing functions as arguments and returning functions
- Code modularization: creating modules, importing, and using `if __name__ == '__main__'`

Hands-on objectives:

- Write reusable functions with clear parameter contracts and return values
- Use `*args`/`**kwargs` to accept flexible argument lists
- Apply `lambda`, `map`, `filter`, `reduce` to process lists concisely
- Split code into modules and import them in a runner script

Notes for exercises: show function signatures and examples; small project demonstrates modularization. Two challenging assignments test `*args/**kwargs`, lambdas, and building small higher-order utilities.

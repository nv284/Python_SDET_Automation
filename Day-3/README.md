Day 3 - Functions & Functional Programming

This folder contains lessons, examples, a small project, and two assignments focused on:

- Defining and calling functions (parameters, return values)
- Variable arguments: `*args` and `**kwargs`
- Lambda expressions and short anonymous functions
- Functional programming basics: `map`, `filter`, `reduce` (usage examples)
- Code modularization: splitting logic across modules and importing

Work through `lessons/lesson.md`, run the example scripts in `examples/`, then try the `projects/` and `assignments.txt` tasks.

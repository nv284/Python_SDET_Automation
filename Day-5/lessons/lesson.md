File Handling, Exception Handling & Logging - Lesson

Topics covered:

- File operations:
  - Text files: open/read/write, context managers
  - CSV: reading and writing with `csv` module
  - JSON: serialize/deserialize with `json` module
- Test data management: storing fixtures, reading bulk data for tests
- Exception handling strategies:
  - `try`/`except`/`else`/`finally`
  - Raising and creating custom exceptions
  - When to catch vs propagate
- Logging:
  - Using the `logging` module
  - Log levels, formatters, handlers
  - Simple logging framework pattern for test runs
- Debugging fundamentals:
  - Using `print` vs `logging`
  - Using `pdb` and common debugging steps

Hands-on objectives:

- Read and write text, CSV, and JSON test data
- Implement robust exception handling with clear messages
- Add logging to trace program flow and errors
- Build a small project that manages test data files and logs actions

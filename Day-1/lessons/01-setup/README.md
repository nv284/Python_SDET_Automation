# Lesson 01 — Installation & Environment Setup

Goals
- Create a reproducible Python environment using `venv`.
- Install and verify `pytest` for lesson tests.

Instructor notes
- Provide Windows and cross-platform commands. This workspace includes `setup.ps1` for Windows.

Student tasks
1. Run `setup.ps1` (Windows) to create `.venv` and install `pytest`.
2. Activate the venv and verify Python: `python --version`.
3. Run `pytest -q` in the repo root to confirm tests (none yet).

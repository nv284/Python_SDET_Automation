# Lesson 02 — Variables & Memory

Topics
- Variable assignment, names, and basic memory concept
- Mutability vs immutability
- Scope (local vs global)

Starter file: `examples/variables_example.py`

Student tasks
1. Assign variables for name, age, and balance — print them.
2. Modify a mutable object and observe effects.
3. Create a function that changes a local variable and show scope.
